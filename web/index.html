What counts as cross-border evidence?

For each sampled day the tool reads existing Canadian IPv4 anchor-mesh results from 18:00 to 20:00 UTC. Only traces that reached the destination enter the percentage. A US exchange match requires a responding address listed for a member interface at an exchange whose published facilities are all in the US. The same rule applies to Canadian exchanges.

These addresses identify exchange infrastructure. Remote peering and unlocated hops limit geographic certainty. A trace without a US exchange match can still cross the border. One trace can match both countries. Blank directions have no recorded sample.
